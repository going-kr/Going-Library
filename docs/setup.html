개발 환경 구성

Going Library를 사용하는 .NET 프로젝트를 만들고 배포하기 위한 최소 구성

Going Library는 NuGet 패키지로만 제공되는 일반 .NET 라이브러리입니다. 별도의 SDK 설치나 전용 도구 없이 dotnet CLI만으로 프로젝트를 만들고 실행할 수 있습니다.

사전 요구사항

항목 요구 확인 명령
.NET SDK 8.0 이상 dotnet --version
에디터 Visual Studio / VS Code / Rider 등 (선택) —

프로젝트 생성과 패키지

콘솔 프로젝트를 만들고 UI 어댑터와 통신 라이브러리를 추가합니다. 

dotnet new console -n MyHMI
cd MyHMI

# UI (OpenTK 어댑터 — Going.UI 코어를 함께 가져옵니다)
dotnet add package Going.UI.OpenTK

# 통신 (Modbus / MQTT / CNet / MC)
dotnet add package Going.Basis

어댑터 선택

패키지 용도 대상
Going.UI.OpenTK 임베디드 터치 패널, Raspberry Pi, 데스크톱 net8.0
Going.UI.Forms WinForms 앱에 UI 캔버스를 얹는 경우 net8.0-windows
Going.UI 플랫폼 독립 코어만 필요한 경우 (어댑터가 참조) net8.0

.gudx 출력 복사 설정

화면은 .gudx 마크업 파일을 런타임에 읽어 구성합니다. 마크업 파일이 실행 디렉터리에 있어야 하므로 .csproj에 복사 항목을 추가합니다. 

<ItemGroup>
  <None Update="ui\**" CopyToOutputDirectory="PreserveNewest" />
</ItemGroup>

이미지·폰트 등 다른 리소스 폴더도 같은 방식으로 추가하면 됩니다.

Raspberry Pi 배포

64비트 Raspberry Pi OS 등 linux-arm64 대상은 다음과 같이 게시합니다. 대상 장치에 .NET 런타임을 따로 설치하지 않으려면 --self-contained를 사용합니다. 

# 런타임 포함 게시 (대상 장치에 .NET 설치 불필요)
dotnet publish -c Release -r linux-arm64 --self-contained true -o publish

# 대상 장치에 .NET 8 런타임이 이미 있는 경우
dotnet publish -c Release -r linux-arm64 --self-contained false -o publish

publish 폴더를 장치로 복사한 뒤 실행 권한을 부여하고 실행합니다. ui/*.gudx를 비롯한 리소스도 함께 복사되었는지 확인하세요.

시각 설계 · AI 워크플로우

Senvas — HMI UI 에디터 & AI 개발

화면을 손으로 배치하며 설계하거나, 프로젝트 골격 생성·AI 연동 워크플로우가 필요하다면 Going Library 위에 만들어진 통합 개발 도구 Senvas를 사용하세요.

  • .gudx 화면을 시각적으로 설계하고 검증
  • MakeCode로 C# 프로젝트 골격 생성
  • Claude Code 등 외부 AI 도구와 연동된 프로젝트 생성·수정 워크플로우 (요구사항 인터뷰 → 설계 → 구현 → 검증)
  • 빌드 및 대상 장치 배포

github.com/going-kr/Release.Senvas ↗

라이브러리 자체는 Senvas 없이도 독립적으로 사용할 수 있습니다.
