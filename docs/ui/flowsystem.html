FlowSystem

네임스페이스 Going.UI.FlowSystem — 산업용 배관 흐름 시뮬레이터

FsFlowSystemPanel이 배관 네트워크 전체를 관리하는 컨테이너입니다. 펌프·밸브·탱크·파이프 분기 같은 컴포넌트(모두 FsFlowObject 파생)를 Childrens에 배치하고, 두 컴포넌트의 포트를 잇는 FlowConnection을 Connections에 추가해 배관을 연결합니다. 각 컴포넌트는 IoPorts()로 자신의 ConnectPort(입력/출력/양방향)를 노출하며, FlowConnection.StartControlId/StartPortName과 EndControlId/EndPortName으로 두 포트를 참조합니다. 배치나 연결을 런타임에 바꾼 뒤에는 FsFlowSystemPanel.RefreshCache()를 호출해 내부 캐시를 갱신해야 합니다(초기 OnInit 시에는 자동 호출).

매 Draw 사이클마다 시작점(UseOutlet=true인 FsCylinderTank, 모든 FsSiloTank, UseInlet=false인 FsPump의 Outlet 포트)에서 출발해 연결된 포트를 따라 재귀적으로 흐름 상태와 유체 색을 전파합니다 — 경로상의 모든 컴포넌트가 IsFlow=true여야 흐름이 계속 전달되며, FsTeePipe/FsCrossPipe에서 서로 다른 색이 합류하면 MixedColor로 표시됩니다. 흐름이 있는 배관에는 10ms 간격 내부 타이머가 300ms마다 흰색 반투명 버블을 흘려보내 시각적으로 흐름을 표현합니다. FsPump/FsValve/FsTeePipe/FsCrossPipe는 IRotatable을 구현해 0/90/180/270도 회전 시 포트 위치·방향이 자동 재배치됩니다. 경로 스무딩/정규화 등 저수준 계산은 내부 PipeTool 유틸리티가 담당합니다(직접 호출 대상 아님).
