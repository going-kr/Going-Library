Shapes

네임스페이스 Going.UI.Controls.Shapes — 벡터 셰이프 (사각형/원/선/호/다각형/베지에)

모든 셰이프는 공통 베이스 GsShape를 상속하며, Fill(단색/선형/방사형)·Stroke·Shadow·Glow·Rotation·Clip을 동일한 방식으로 처리합니다. 각 파생 클래스는 자신의 기하(경로)만 정의합니다. Fill이 null이면 채우지 않고, StrokeColor가 null이면 테두리를 그리지 않습니다 — 두 값을 모두 지정하지 않으면 아무것도 보이지 않으니 주의하세요. 색상 값은 테마 색 키("Point", "Base3" 등) 또는 "#FF8800" 같은 직접 색상 코드를 사용합니다.

GsLine/GsPolygon/GsBezier의 점 좌표는 Bounds 기준 정규화 좌표입니다 — "x,y x,y …" 형식의 공백 구분 문자열이며 각 값은 0~1 범위(0=왼쪽/위, 1=오른쪽/아래)입니다. 컨트롤 크기가 바뀌어도 좌표가 자동으로 스케일됩니다.

public abstract class GsShape : GoControl
벡터 셰이프의 베이스. 공통 효과(채움/테두리/그림자/글로우/회전/클립)를 일괄 처리하고, 파생 셰이프는 경로만 정의합니다. 색은 테마 색 키("Point", "#FF8800" 등).
Properties — Fill
string?Fill get set채움 색(테마 색 키). null이면 채우지 않음
GsFillTypeFillType get set채움 방식(단색/선형/방사형). 기본값: Solid
string?FillColor2 get set그라데이션 끝 색. null이면 Fill 사용
floatGradientAngle get set선형 그라데이션 방향(도). 0=좌→우, 90=상→하. 기본값: 90
Properties — Stroke
string?StrokeColor get set테두리 색. null이면 그리지 않음
floatStrokeWidth get set테두리 두께. 기본값: 1
Properties — Shadow / Glow
string?ShadowColor get set그림자 색. null이면 그림자 없음
floatShadowX get set그림자 X 오프셋. 기본값: 0
floatShadowY get set그림자 Y 오프셋. 기본값: 2
floatShadowBlur get set그림자 흐림 정도. 기본값: 4
string?GlowColor get set글로우 색. null이면 글로우 없음(오프셋 0의 외곽 블러)
floatGlowBlur get set글로우 흐림 정도. 기본값: 8
Properties — Transform / Clip
floatRotation get set회전 각도(도). Bounds 중심 기준. 기본값: 0
boolClip get setBounds로 클리핑할지. false면 효과/회전이 Bounds 밖으로 그려질 수 있음. 기본값: true

Properties
floatCornerRadius get set모서리 반지름. 기본값: 0
public class GsCircle : GsShape
원/타원 셰이프. Bounds에 맞춰 그리므로 정사각이면 원, 아니면 타원입니다.
Properties
추가 속성 없음 — GsShape 공통 속성만 사용
public class GsLine : GsShape
직선 셰이프(stroke 전용). 점은 공백 구분 정규화 좌표("x,y x,y", 0~1)입니다.
Properties
stringPoints get set두 끝점(정규화 0~1, 공백 구분). 기본값: "0,0.5 1,0.5"(가로 중앙선)
public class GsArc : GsShape
호(arc) 셰이프. 원형 게이지/장식에 사용합니다. 두께/색은 베이스의 Stroke를 씁니다. 각도는 Skia 기준(3시=0도, 시계방향 +).
Properties
floatStartAngle get set시작 각도(도). 3시=0, 시계방향 +. 기본값: 135
floatSweepAngle get set스윕 각도(도). 기본값: 270
public class GsPolygon : GsShape
다각형/폴리라인 셰이프. 점은 공백 구분 정규화 좌표("x,y x,y", 0~1). Closed면 닫혀서 fill 가능.
Properties
stringPoints get set꼭짓점(정규화 0~1, 공백 구분). 기본값: "0.5,0 1,1 0,1"(삼각형)
boolClosed get set경로를 닫을지(닫으면 fill 가능). 기본값: true
public class GsBezier : GsShape
3차 베지에 곡선 셰이프. 점은 공백 구분 정규화 좌표("x,y x,y", 0~1)이며 [start, c1, c2, end, c1, c2, end, …] 형태로 4점 이후 3점씩 세그먼트를 잇습니다. Closed면 닫혀서 fill 가능.
Properties
stringPoints get set제어점(정규화 0~1, 공백 구분). 기본값: "0,1 0.3,0 0.7,0 1,1"(1개 큐빅 세그먼트, U자)
boolClosed get set경로를 닫을지(닫으면 fill 가능). 기본값: false

FillType에 사용하는 GsFillType 열거형(Going.UI.Enums)의 전체 멤버는 Enums › GsFillType에서 확인하세요.

.gudx 예시

셰이프는 다른 컨트롤과 동일하게 .gudx 마크업에 태그로 배치합니다. 아래는 그라데이션 채움 사각형과 게이지 느낌의 호를 함께 배치한 예시입니다.

<!-- 그라데이션 채움 사각형 -->
<GsRect Bounds="20,20,180,100"
        Fill="Point" FillType="Linear" FillColor2="Base1" GradientAngle="90"
        StrokeColor="Base4" StrokeWidth="2"
        CornerRadius="8"
        ShadowColor="Base5" ShadowX="0" ShadowY="2" ShadowBlur="4" />

<!-- 진행률 호 게이지 -->
<GsArc Bounds="220,20,300,100"
       StrokeColor="Point" StrokeWidth="10"
       StartAngle="135" SweepAngle="180" />

<!-- 정규화 좌표 폴리곤(삼각형 화살표) -->
<GsPolygon Bounds="320,20,380,80"
           Points="0.5,0 1,1 0,1" Closed="true"
           Fill="Warn" />
