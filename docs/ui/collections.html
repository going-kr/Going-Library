public interface IGoCellIndexedControlCollection
셀 인덱스 기반 컨트롤 컬렉션(GoTableLayoutControlCollection, GoGridLayoutControlCollection)의 공통 헬퍼 API입니다. GoGudxConverter가 두 컬렉션을 단일 코드 경로로 처리할 때 사용합니다. 각 구현체는 기존 고유 형태(GoTableIndex / GoGridIndex)를 유지하며, 이 인터페이스는 열거/추가 헬퍼만 제공합니다. 셀 병합(ColSpan/RowSpan)은 GoTableLayoutControlCollection만 지원하며, GoGridLayoutControlCollection은 EnumerateCells에서 항상 (1,1)을 보고하고 AddCell의 span 인자를 무시합니다.
Properties

Methods
IEnumerable<(IGoControl Control, int Column, int Row, int ColSpan, int RowSpan)>EnumerateCells()모든 셀을 (컨트롤, 열, 행, 열병합, 행병합) 형태로 열거. 병합 미지원 컬렉션은 (1, 1) 반환
voidAddCell(IGoControl c, int col, int row, int colSpan = 1, int rowSpan = 1)지정된 셀 위치에 컨트롤 추가. 병합 미지원 컬렉션은 colSpan/rowSpan 무시
