명도 modifier (가산 방식, 단위 8L)

예시의미
"Base2-light"Base2보다 한 단계(+8L) 밝은 색
"Fore-dark-3"Fore보다 세 단계(-24L) 어두운 색
"#FF3366"지정 RGB hex 색상 (modifier 없이 그대로)

GoDesign.CustomTheme는 [GoChildSingle](B1) + [GudxTagName("Theme")]로 선언되어 있어, .gudx로 저장하면 GoTheme의 모든 속성이 단일 자식 엘리먼트의 속성으로 박제됩니다: <Theme Dark="true" Fore="#FFFFFF" Back="#323232" .../>. CustomTheme이 null이면 <Theme> 엘리먼트 자체가 생략되고 DarkTheme이 사용됩니다.

public class DarkTheme : GoTheme
라이브러리 내장 기본 다크 팔레트. GoTheme.DarkTheme 정적 프로퍼티로 접근하며, GoDesign.CustomTheme이 null일 때 자동 적용됩니다. 현재 이 파생 테마 하나만 내장되어 있고 별도의 LightTheme 클래스는 없습니다 — 밝은 테마가 필요하면 GoTheme 인스턴스를 직접 만들어 CustomTheme에 지정하세요.
