Getting Started

.gudx 마크업으로 화면을 만들고 데이터에 바인딩해 첫 HMI를 실행합니다

시작하기 전에 — .NET 8 SDK가 필요합니다. 설치 확인과 배포 옵션은 개발 환경 구성을 참고하세요.

개요

화면은 .gudx XML 마크업으로 선언하고, 데이터 연결은 {path} 바인딩 식으로 처리합니다. 코드 생성 도구 없이 라이브러리만으로 동작합니다.

단계 작업 파일
Step 1프로젝트 생성과 패키지 추가MyHMI.csproj
Step 2화면 마크업 작성ui/Main.gudx
Step 3디자인 로드 · 페이지 설정 · 바인딩 연결Program.cs
Step 4빌드 및 실행—
Step 5통신 연결 · 컨트롤 레퍼런스 · 시각 설계 도구—

Step 1 — 프로젝트 생성과 패키지 

dotnet new console -n MyHMI
cd MyHMI
dotnet add package Going.UI.OpenTK
dotnet add package Going.Basis

.gudx는 런타임에 읽는 파일이므로 출력 디렉터리로 복사되도록 MyHMI.csproj에 항목을 추가합니다. 

<ItemGroup>
  <None Update="ui\**" CopyToOutputDirectory="PreserveNewest" />
</ItemGroup>

Step 2 — ui/Main.gudx 작성

ui 폴더를 만들고 Main.gudx를 작성합니다. GoDesign 아래에 Pages → GoPage → Childrens 순으로 컨트롤을 배치합니다. 

<GoDesign>
  <Pages>
    <GoPage Name="Main" BackColor="Back">
      <Childrens>
        <GoLabel  Text="{Status}"      Bounds="12,10,348,44" FontSize="20" TextColor="Point"/>
        <GoLabel  Text="{Motor.Rpm:F0}" Bounds="12,52,348,96" FontSize="26"/>
        <GoButton Text="START"         Bounds="12,110,348,160" Name="btnStart"/>
      </Childrens>
    </GoPage>
  </Pages>
</GoDesign>

Bounds는 Left,Top,Right,Bottom 입니다. {Status}, {Motor.Rpm:F0}는 바인딩 식으로, Step 3의 데이터 객체 속성 경로를 가리킵니다.

Step 3 — Program.cs

GoGudxConverter.ReadGoDesign으로 마크업을 GoDesign으로 읽고, GoViewWindow에 할당한 뒤 SetPage로 시작 페이지를 지정하고 WireBindings로 데이터 객체를 연결합니다. 

using System.Xml.Linq;
using Going.UI.Design;
using Going.UI.Gudx;
using Going.UI.OpenTK.Windows;
using OpenTK.Windowing.Common;

var hub = new AppHub();
var design = GoGudxConverter.ReadGoDesign(XElement.Load("ui/Main.gudx"))
             ?? throw new InvalidOperationException("gudx 파싱 실패");

using var win = new MainWindow(design, hub);
win.Run();

public sealed class MotorVM { public double Rpm { get; set; } }

public sealed class AppHub
{
    public string Status { get; set; } = "RUN";
    public MotorVM Motor { get; } = new() { Rpm = 1450 };
}

public sealed class MainWindow : GoViewWindow
{
    private readonly AppHub hub;

    public MainWindow(GoDesign design, AppHub hub)
        : base(1024, 600, WindowBorder.Hidden)
    {
        Design = design;
        this.hub = hub;
    }

    protected override void OnLoad()
    {
        base.OnLoad();
        Design.SetPage("Main");
        Design.WireBindings(hub);   // 마크업의 {…} 식을 hub에 연결
    }
}

마스터 파일과 참조 파일로 나눠 관리한다면 GoDesign.DeserializeGudx(masterPath)를 사용할 수도 있습니다.

Step 4 — 실행 

dotnet build
dotnet run

1024 × 600 창이 뜨고 마크업으로 선언한 화면이 그려집니다. 렌더 루프가 매 프레임 hub와 컨트롤을 동기화하므로, hub.Motor.Rpm 값을 바꾸면 화면이 따라갑니다.

실행 시 ui/Main.gudx를 찾지 못하면 Step 1의 CopyToOutputDirectory 설정을 확인하세요.

Step 5 — 다음 단계

통신 연결 (Going.Basis)

데이터 객체(AppHub)의 속성을 통신 캐시 값으로 채우면 화면이 실제 장치를 따라갑니다. 

// Modbus RTU Master
var rtu = new MasterRTU();
rtu.MonitorHoldingRegister_FC3(1, 0x0000, 50);
rtu.Start();

var value = rtu.GetHoldingRegister(1, 0);   // 캐시에서 읽기
rtu.WriteHoldingRegister_FC6(1, 0, 100);    // 장치에 쓰기

프로토콜별 클래스: Modbus · MQTT · LS CNet · Mitsubishi MC
