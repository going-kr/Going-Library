Getting Started

라이브러리만으로 첫 화면을 띄우는 과정. 프로젝트 생성 → ui/Main.gudx 작성 → Program.cs 연결 → 실행까지 한 흐름으로 안내합니다.

.gudx 바인딩 OpenTK
Senvas

HMI UI 에디터 & AI 개발

Going Library 위에 만들어진 HMI 통합 개발 도구. .gudx 화면을 시각적으로 설계·검증하고, MakeCode로 C# 프로젝트 골격을 생성하며, 외부 AI 도구와 연동된 프로젝트 생성·수정 워크플로우와 장치 배포를 지원합니다.
