이 폴더에는 아직 구현되지 않은 장래 발명과 청구항 아이디어가 포함되어 있다. 공개 저장소에 commit/push하거나 NuGet·문서·발표로 공개하기 전에 반드시 출원 또는 비밀관리 여부를 확인한다.
