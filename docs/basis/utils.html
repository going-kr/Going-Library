public enum EndianOrder
32비트 값을 Modbus 워드 배열로 변환할 때 사용할 바이트/워드 순서. A, B, C, D는 원본 값을 big-endian 바이트 순서로 보았을 때의 각 바이트.
Values
ABCD (Big-endian. bytes: A B C D, words: AB CD) BADC (Byte-swap. bytes: B A D C, words: BA DC) CDAB (Word-swap. bytes: C D A B, words: CD AB) DCBA (Little-endian. bytes: D C B A, words: DC BA)
